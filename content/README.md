# Навыки для импорта

Архивы навыков с инструментами. Они выходят отдельно от релизов Camomile и ставятся обычным импортом.

## Установка

1. Вкладка «Навыки» → «📥 Импорт» → архив, пароль пакета.
2. Вкладка «Инструменты» → «📥 Импорт» → тот же архив и пароль. Если начать с инструментов, агент предложит привязать их к новому навыку.
3. Откройте инструменты навыка, прочитайте код и отметьте «Код проверен».
4. Включите навык в чате.

Новая версия навыка ставится так же, в режиме «Перезаписать элементы с совпадающими id». После обновления код инструментов проверяется заново, включённость навыка в чатах сохраняется.

## SAP ADT

Чтение объектов ABAP через SAP ABAP Development Tools (ADT). Навыки выходят по одному, состав — в таблице ниже.

Пароль архивов: `camomile-sap-adt`. Инструменты лежат в папке «SAP ADT», навыки — в папке «Прикладные / SAP ADT».

| Архив | Навык | Версия | Инструменты |
|---|---|---|---|
| `sap-adt-00-systems-1.1.0.json` | SAP: системы | 1.1.0 | `sap_system`, `sap_check` |

Справочник систем и мандантов и текущая запись хранятся в памяти агента: sap.systems, sap.current (одна запись на весь агент), sap.settings (язык и вход Windows, общие для всех систем). Любой инструмент пакета при первом вызове сам спросит систему формой.

Запросы идут методом GET через локальный хост. Запись без манданта («S4D») — мандант системы по умолчанию и вход Windows: нужен Java-прокси, сопряжённый с агентом, хост SAP в его allowlist и отметка «Разрешить SSO» в «Настройки → Локальный хост». Запись с мандантом («S4D/200») — вход пользователем SAP: пароль вводится в окне приложения при первом запросе и хранится зашифрованным, в резервную копию не попадает.

Навыкам пакета нужна сборка Camomile r36 с папкой content и входом по паролю для инструментов (agent_secret) или новее.

В режиме безопасности «Оптимальный» спрашивается каждый запуск кода инструмента и каждый запрос со входом Windows. В режимах «Минимальный» и «Отключено» запуск не спрашивается, а вход Windows можно разрешить для инструмента до перезагрузки страницы.
